
# SmartInvest.SCU

Aplikasi analisis saham berbasis web yang menyediakan informasi perusahaan,
data saham, analisis teknikal, dan rekomendasi investasi.

## About Project

SmartInvest.SCU merupakan proyek akademik mata kuliah Financial Technology.

## My Role

Backend Developer (Team Project)

## Technologies

### Backend
- Python
- Flask
- Flask-SQLAlchemy
- MySQL
- JWT Authentication

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Data Analysis
- Pandas
- yfinance
- Technical Analysis Library (ta)

## Features

- User Registration and Login
- JWT Authentication
- Company Information API
- Current Stock Data API
- Technical Analysis API
- Stock Recommendation API
- Analysis History
- PDF Report Export

## Project Structure

- SmartInvest_Backend/
- SmartInvest_Frontend/

## Installation

1. Clone this repository.
2. Create a Python virtual environment.
3. Install dependencies from requirements.txt.
4. Configure environment variables.
5. Configure the MySQL database.
6. Run the Flask application.
